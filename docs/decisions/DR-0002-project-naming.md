# DR-0002: プロジェクト名 "hyoui" の決定

- Status: Active
- Date: 2026-05-21
- Related: DR-0001 (「一心同体」概念がこの命名の根拠と地続き)

## Context

poc3（shimux の PTY プロキシ PoC）をベースに新規リポを起こすにあたり、名前が必要に
なった。命名の議論を通じて、ツールの性格そのものも言語化が進んだ。

### ツールの性格（命名議論で固まった像）

- 基本は **何もしない透過的なラッパー**（IO/tty にフックを掛け、マッチがあれば
  イベント発火・書き換えをする程度）
- 子プロセスに **着せる衣・装備品** のようなイメージ
- 親子が **一心同体・一蓮托生** — 親が死ねば子も、子が死ねば親も（DR-0001 の invariant）
- **headless では外部からの操縦ハンドル**になる。子は PTY を持つので「自分は tty 上で
  動いている」と思い込むが、その入力はまるごと外部から来る。tty プログラムを外から
  操る ＝ 憑依・呪縛的な側面

## Decision

プロジェクト名は **`hyoui`**（憑依）。

### 採用理由

- **概念一致**: 憑依 = 何かが宿って一体化し、宿主は一見ふつうに見えるが内側から
  動かしうる。「同居する別人格」「一心同体」「一蓮托生の生き死に」「headless での
  操縦」を 1 語で全部含む。
- **主体が正しい**: 「ツールが子に憑依する」── ツールが憑依する側（主体）であり、
  傀儡（操られる側）を名にするのと逆で自然。
- **命名流儀の一貫性**: romaji 表記 `hyoui` は `kuu`（くう→kuu）と同じ「長音を母音
  重複で書く」流儀で、kawaz の MoonBit リポ命名（kuu / shimux）と揃う。
- **検索性**: 英単語と違い `hyoui` という綴りは固有性が高く、コンフリクトしにくい。

### 既知の弱点とその緩和

英語話者には読みづらい。綴り中に仏語 "oui"（wee）や "you" を拾ってしまい、
"hyo-wee" / "high-wee" 等にブレる。語頭 "hy-" も /haɪ/ か /hjuː/ か曖昧。

- 正しい音は /ˈhjoʊi/（ヒョーイ）。ヘボン式正式表記は `hyōi`（マクロンは
  ASCII にできずコマンド名で実用外）。
- 緩和策: **README 冒頭に発音表記 `/ˈhjoʊi/` を記載**する。個人 public リポなので
  英語話者の読みブレは飲めるコストと判断。

## 検討した不採用案

命名は多くの方向を経た。主な不採用候補と理由（要約）:

| 方向 | 候補 | 不採用理由 |
|---|---|---|
| pty 直球 | ptylens / ptytap / ptyhook / ptyup | pty を前面に出す必要なし。"lens" は AI 多用語で CLI に気取りすぎ。"tap" は idiomatic だが pty 前面化を避けた |
| 伴走・被覆 | chaperone / sidecar / escort / sheath | chaperone 長い、sidecar はコンテナ連想、escort よそよそしい、sheath は監督ニュアンス無し |
| 魂の片割れ | anima / symbiont / caul / tether | anima は別の生々しい連想、他は馴染み薄い |
| 寄生・分身 | remora / umbra / mantle / guise | 馴染み薄い／「化ける」寄り |
| ポップ語 | symbiote / exo / parasite / pod | symbiote 厨二寄り、parasite はネガティブ、exo 漠然、pod は k8s 連想 |
| 複合語（2 語可） | secondskin / kagegoromo / hagoromo / norogoromo | 1 語固執を緩めた段階の案。最終的に 1 語の hyoui に着地 |
| 神話系 | fylgja / ka / luonto / pollux | 北欧・エジプト・フィン・ギリシャ。概念は合うが馴染み薄い |
| 日本妖怪・伝承 | hiyoku / kudagitsune / michizure / bunshin | 比翼の鳥は概念的に強かったが、最終的に憑依に |
| 御簾・取次の比喩 | misu / toritsugi | 「中継役」「薄い隔ての膜」。憑依に一歩譲った |
| 合体ロボ系 | gattai / fusion | 「合体して一体」。憑依の方が「同居・操縦」まで含む |

「1 語にこだわらず 2 語まで可」と途中で制約を緩めたが、最終的に 1 語の `hyoui` で
概念被覆・命名流儀・検索性が噛み合った。

## 補足

`hyoui` は議論の中でユーザ自身が出した語。憑依という語が、それまでに言語化されていた
「透過・一心同体・操縦ハンドル」の像を後付けでなく綺麗に回収した点が決め手になった。
